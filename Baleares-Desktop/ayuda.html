Funcionamiento general del sitio

Este sitio web permite consultar información turística sobre las Islas Baleares, incluyendo gastronomía, rutas, meteorología, un juego de preguntas y un sistema de reservas de recursos turísticos.

Opciones del menú de navegación

Inicio

La página principal presenta el proyecto, una introducción a Baleares, un carrusel de imágenes y una sección de noticias.

Gastronomía

Muestra información sobre platos, productos e ingredientes típicos de las Islas Baleares. Incluye listas, una tabla accesible y recursos multimedia.

Rutas

Permite consultar rutas turísticas por Baleares cargadas desde un archivo XML. Cada ruta mostrará información textual, planimetría en formato KML y altimetría en SVG.

Meteorología

Muestra información meteorológica actual y previsión para los próximos siete días en la capital de Baleares.

Juego

Contiene un test de diez preguntas sobre el contenido del sitio web. Cada pregunta tiene cinco respuestas posibles y solo una correcta.

Reservas

Permite registrar usuarios, consultar recursos turísticos disponibles, realizar reservas, obtener presupuestos y anular reservas.

Ayuda

Explica cómo utilizar cada parte del sitio web y sirve de apoyo para las pruebas de usabilidad.

Consejos de uso

  • Utilice el menú superior para cambiar de sección.
  • Revise las migas de navegación para saber en qué página se encuentra.
  • En la página de rutas, seleccione la ruta turística que desea consultar.
  • En reservas, registre un usuario antes de intentar confirmar una reserva.
  • En el juego, responda todas las preguntas antes de finalizar.

Tareas de usabilidad

Para las pruebas de usabilidad se comprobará que el usuario puede jugar al juego, encontrar la duración de una ruta turística y realizar una reserva con presupuesto.
